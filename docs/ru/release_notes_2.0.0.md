# Изменения в Temporal Boost 2.0.0 {#release-notes-temporal-boost-200}

Это исторические заметки о выпуске 2.0.0. Текущее поведение описано в руководствах и справочнике API; в репозитории снова есть тесты.

## 🚀 Основные изменения {#major-changes}

### Структура проекта {#project-restructure}

- Логика Temporal перенесена в `temporal_boost/temporal/`: клиент, конфигурация, runtime и воркер.
- Новый пакет `workers/` содержит отдельные воркеры ASGI (uvicorn, hypercorn, granian) и Temporal.
- Удалены устаревшие внутренние модули: `connect.py`, `core.py`, `logger.py`, `schemas.py`, `tracing.py`, прежний `worker.py`.
- Примеры обновлены под новую структуру.

### Настройка через переменные окружения {#configuration-via-environment-variables}

- Настройки клиента и воркера задаются через переменные окружения (см. `temporal_boost/temporal/config.py`).
- В этом выпуске прямые параметры endpoint, namespace и logger у `BoostApp` заменены настройками окружения.

### Новые сборщики и расширяемость {#new-builders-and-extensibility}

- `TemporalClientBuilder`, `TemporalWorkerBuilder` и функции создания runtime для расширенной настройки.
- Гибкая настройка runtime и клиента.

### Реестр воркеров ASGI {#asgi-worker-registry}

- Поддержка uvicorn, hypercorn и granian с автоматическим выбором.
- Подключение FastAPI или другого приложения ASGI как воркера.

### DevOps и инструменты {#devops-and-tooling}

- Обновлены зависимости, хуки pre-commit, задачи VSCode и процесс разработки.
- Поддержка Poetry 2.x.

### Удаление тестов {#tests-removed}

- В выпуске 2.0.0 удалены тесты и фикстуры с намерением переработать их в будущих версиях.

---

## ⚠️ Несовместимые изменения {#breaking-changes}

- Прежний API инициализации `BoostApp` и регистрации воркеров больше не поддерживается.
- Конфигурация задаётся переменными окружения или новыми классами сборщиков.
- Внутренний воркер документации удалён.
- В этом выпуске из репозитория удалены тесты и фикстуры.

---

## 🛠 Руководство по миграции {#migration-guide}

1. **Обновите импорты**: используйте `temporal_boost.temporal` и `temporal_boost.workers`.
2. **Перенесите конфигурацию** endpoint, namespace, TLS и метрик в окружение. См. `temporal_boost/temporal/config.py`.
3. **Обновите регистрацию воркеров**:

     ```python
     app.add_worker("worker_1", "queue_1", activities=[...], workflows=[...])
     ```

   Для ASGI:

     ```python
     app.add_asgi_worker("asgi_worker", fastapi_app, "0.0.0.0", 8000, worker_type="auto")
     ```

4. **Удалите использование внутреннего воркера документации**.
5. **Обновите примеры**, ориентируясь на каталог `examples/` и документацию.

## 🆕 Новые возможности {#new-features}

- Настройка всех основных параметров через окружение.
- Подключаемые типы воркеров ASGI с автоматическим выбором.
- Более модульная архитектура и дополнительные точки расширения.
- Упрощённая организация кода.
