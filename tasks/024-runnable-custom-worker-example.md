# TB-024. Сделать пример пользовательского worker исполнимым

- **Статус:** done
- **Приоритет:** P3
- **Тип:** Баг в примере

## Проблема и подтверждение

`TestAsyncRuntime` в [example_app.py](../examples/example_app.py) наследует [BaseBoostWorker](../temporal_boost/workers/base.py), но не реализует абстрактный `shutdown()`. Его нельзя создать как есть; экземпляр также не регистрируется, хотя пример заявляет custom async runtime.

Пример точки расширения не даёт пользователю рабочего образца и скрывает обязательный lifecycle-контракт.

## Что сделать

1. Реализовать управляемое завершение и обязательный `shutdown()` в примере.
2. Задать имя и показать реальную регистрацию через поддерживаемый custom-worker API.
3. Сделать остановку цикла наблюдаемой; не оставлять бесконечную задачу без stop-механизма.
4. При необходимости выделить компактный отдельный пример, чтобы его проверка не требовала ASGI/Temporal.

## Критерии приёмки

- [x] Класс инстанцируется и соответствует `BaseBoostWorker`.
- [x] Из примера видно, как зарегистрировать, запустить и остановить custom worker.
- [x] Smoke-проверка завершается за ограниченное время без внешних сервисов.
- [x] README примеров указывает актуальную команду запуска.

## Проверка

Тест инстанцирования и короткого lifecycle с явным stop. Дополнительно проверить импорт примера с заявленным набором optional dependencies.

## Результат выполнения

`TestAsyncRuntime` теперь наследует AsyncBoostWorker, реализует run_async()/shutdown(), использует
наблюдаемый asyncio.Event и реально зарегистрирован как `custom_runtime`. Его можно запустить
отдельно в comprehensive example и остановить через Ctrl+C. Компактный `example_custom_worker.py`,
добавленный в TB-018, остаётся вариантом без optional integrations и внешних сервисов.

Два bounded lifecycle теста проверяют регистрацию, имя, создание экземпляров и stop event с
`asyncio.wait_for(..., timeout=1)`. Оба прошли в общем unit-прогоне. Все примеры импортированы с
all extras; README содержит команды standalone и comprehensive запусков.

Проверки выполнены после реализации всей серии 020–028 по явному указанию пользователя.
Общие команды и итоги: [результат серии](README.md#проверка-серии-tb-020tb-028).
