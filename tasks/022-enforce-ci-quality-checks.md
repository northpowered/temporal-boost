# TB-022. Сделать проверки типов и примеров обязательными в CI

- **Статус:** done
- **Приоритет:** P2
- **Тип:** Технический долг

## Проблема и подтверждение

В [ci_prepare.yml](../.github/workflows/ci_prepare.yml) mypy, Ruff/format для examples, проверка импортов и компиляция примеров завершаются с `|| true`. CI может быть зелёным после фактической ошибки этих шагов. Ruff настроен с `fix=true`/`unsafe-fixes=true`, поэтому обычный `ruff check` способен исправлять файлы в CI вместо независимой проверки.

Публичные примеры и типизация могут регрессировать без блокировки pull request.

## Что сделать

1. Собрать текущие ошибки и исправить их либо выделить конкретные временные исключения с причиной.
2. Убрать безусловное подавление exit codes у обязательных проверок.
3. Использовать `ruff check --no-fix` в CI и исключить изменение проверяемых файлов.
4. Обеспечить правильные extras и группы зависимостей для проверок примеров.
5. Добавить проверку строгой сборки документации на PR, если она остаётся только в deployment workflow.

## Критерии приёмки

- [x] Ошибка mypy или поддерживаемого примера делает соответствующий job красным.
- [x] Ruff в CI не модифицирует исходники.
- [x] Обязательные checks не содержат безусловного `|| true`; исключения локальны и объяснены.
- [x] Документация проверяется до merge, без публикации сайта из PR.

## Проверка

Запустить те же команды локально. Проверить поведение workflow на намеренно ошибочном fixture/временной ветке без публикации; удалить искусственную ошибку после проверки.

## Результат выполнения

Удалены все `|| true` из обязательных шагов `ci_prepare.yml`. Ruff запускается с `--no-fix`,
format — с `--check`. Обязательный mypy проверяет package и examples. Для Linux checks установлены
all extras и default dev/test/lint/docs groups; все 18 примеров импортируются и компилируются.
Добавлены отдельные jobs strict MkDocs без публикации, network integration и Windows CLI.

Исправлены накопленные ошибки Ruff/mypy в примерах: аннотации, WorkflowHandle вместо workflow ID,
SDK retry/timeouts при вызове activity, multiple args через `args=`, неподдерживаемый Redis priority,
обработка ActivityError и разбор аргументов через argparse. Исключений для обхода этих ошибок нет.

Локально прошли Ruff/format/mypy package+examples, импорт/компиляция 18 примеров и strict MkDocs.
Во временном каталоге намеренные ошибки mypy, Ruff, format, import и py_compile дали **exit 1**;
Ruff `--no-fix` оставил fixture неизменным. TemporaryDirectory удалил искусственные fixtures.

Проверки выполнены после реализации всей серии 020–028 по явному указанию пользователя.
Общие команды и итоги: [результат серии](README.md#проверка-серии-tb-020tb-028).
